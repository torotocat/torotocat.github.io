一个人住，煮了就吃的东西清单

发表于2026-09-11|更新于2026-09-11|生活
|评论数:

标准很硬：只需要一口锅、水、盐，最多加一勺现成调料，不切配、不腌、不煎不炒、不需要第二道工序。全部是一个人住的场景。

一、主食类：煮完就是一顿饭

品名 常见规格 下锅时间
速冻水饺（三全 / 思念 / 湾仔码头 / 必品阁） 1kg ≈ 54 只 浮起后再煮 3 分钟
速冻馄饨 · 云吞 · 抄手 三全上海大馅馄饨 500g×2 袋 ≈ 80 只 浮起后再煮 2 分钟
速冻汤圆 三全 1kg ≈ 84 只 浮起再煮 1 分钟
速冻小笼包 / 奶黄包 / 豆沙包 450g×2 袋 要蒸，不能水煮
挂面 / 龙须面 / 干刀削面 1kg 3–5 分钟
龙口粉丝 / 红薯粉条 / 干土豆粉 300–500g 粉丝 3 分钟，粗粉条 8–10 分钟
干米粉 / 干河粉 / 桂林米粉 1kg 米线 5–8 分钟，河粉 3–5 分钟
意面 / 通心粉 / 螺旋面 500g 8–12 分钟
荞麦面 / 魔芋面 300–500g 荞麦 4 分钟，魔芋面开水烫 1 分钟
袋装螺蛳粉（好欢螺 / 螺霸王 / 螺满地） 300–400g × 5 袋 粉煮 8–10 分钟，再下料包
袋装酸辣粉 / 砂锅土豆粉 / 爆肚粉 / 过桥米线 单袋或桶 3–8 分钟，料包齐全
火锅年糕 / 条状年糕 400g 3–5 分钟，浮起即可
即食燕麦 / 快熟麦片 1kg 开水冲泡，不用煮
藜麦 / 糙米 / 杂粮饭包 500g 15–40 分钟（进阶，费时间）

整个下锅的天然主食——煮一次，既能当饭又能当菜：

品名 时间
甜玉米 / 水果玉米 5–10 分钟
红薯 / 紫薯 25–30 分钟（切块 15 分钟）
土豆 整只 25 分钟，切片 5 分钟
南瓜 / 山药 / 芋头 切块 15–20 分钟
冷冻玉米粒 / 混合蔬菜粒 2 分钟

二、丸子 · 肉 · 海鲜

品名 时间 备注
潮汕牛肉丸 / 牛筋丸 / 撒尿牛丸 3–5 分钟，浮起 火锅丸类里最耐吃
鱼丸 / 墨鱼丸 / 鱼豆腐 / 蟹柳 / 龙虾球 3 分钟 钠高，别天天吃
虾滑 / 鱼滑 3–5 分钟 用勺挖成团下锅，不用手
香肠 / 火腿肠 / 广式腊肠 8–10 分钟 腊肠更适合跟米一起煮饭
冷冻虾仁 / 冻虾 2–3 分钟 变色即捞，久了发柴
巴沙鱼 / 龙利鱼柳 / 鳕鱼块 3 分钟 切厚片不散
鱿鱼圈 / 鱿鱼须 2 分钟 煮久变橡皮
花蛤 / 蛤蜊 / 青口 吐沙后水开 2 分钟，开口即可 不开口的直接扔
扇贝肉 / 冷冻生蚝 2–3 分钟 生蚝涮 1 分钟就够
冻鸡腿 / 鸡翅 / 鸡胸 鸡胸 10–12 分钟，鸡腿 20 分钟 白灼后蘸料就行
午餐肉 / 红烧肉罐头 开罐即食 严格说不算煮，但配面无敌

完全不用煮的肉：即食鸡胸肉真空装、卤蛋 / 茶叶蛋真空装、卤味（鸭脖、鸡爪、牛腱）、豆豉鲮鱼罐头、油浸金枪鱼罐头。开袋开罐就能吃。

三、蛋 · 豆制品

品名 时间 备注
鸡蛋 冷水下锅，水开 6 分钟溏心 / 8 分钟半熟 / 10 分钟全熟 关火焖 2 分钟更好剥
鹌鹑蛋 水开 4 分钟 一口一个
内酯豆腐 / 嫩豆腐 烫 1 分钟（也可以直接吃） 拌生抽 + 香油
北豆腐（老豆腐） 3–5 分钟 切块下锅不散
冻豆腐 3 分钟 吸汤最强
油豆腐 / 豆泡 3 分钟 吸汤，会烫嘴
千张 / 豆腐皮 / 豆干 / 素鸡 2–3 分钟 切条直接下
腐竹 先泡 30 分钟，再煮 3 分钟 唯一需要提前泡的
豆皮结 / 千张结 5 分钟 火锅标配

四、蔬菜：焯水 10 秒到 3 分钟

绿叶类（10–30 秒，捞出淋生抽 + 香油）

生菜、油麦菜、菠菜、小白菜、菜心、娃娃菜、茼蒿、空心菜、芝麻菜、豌豆苗

硬身类（2–5 分钟）

西兰花、菜花、胡萝卜块、藕片、玉米笋、莴笋片、芦笋、秋葵、冬瓜、白萝卜、番茄、豌豆、毛豆（5–10 分钟）、四季豆 / 豆角（必须煮透 5 分钟以上）、荷兰豆（3 分钟）

菌菇与藻类（1–3 分钟）

金针菇、白玉菇、蟹味菇、杏鲍菇、平菇、香菇、干木耳（先泡发）、紫菜、干裙带菜（开水 30 秒就发）、海带结、海带苗

零负担填肚

魔芋结 / 魔芋丝 / 魔芋片（3 分钟，几乎零卡）、绿豆芽（1 分钟）、黄豆芽（3 分钟）、冻西兰花 / 冻混合蔬菜（3 分钟，不用洗切）

五、汤底与调料：决定好吃还是难吃

上面这些东西本身大多没什么味道，好吃与否全看锅里那勺东西。

品名 用法
火锅底料（好人家 / 名扬 / 海底捞 / 桥头） 一人食买 50g 独立小块最划算，一块正好一锅
番茄火锅汤料（不辣） 煮面煮菜都行，比麻辣底料更经得起天天吃
浓汤宝 / 汤宝 / 鸡精块 1L 水放一块
味噌 / 韩式大酱 / 韩式辣酱 一勺化开就是一锅汤
紫菜 + 虾皮 + 干裙带菜 最便宜的鲜味来源，泡开就香
生抽 / 味极鲜 / 蒸鱼豉油 焯菜淋这个就够了
香油 / 芝麻酱 / 花生酱 拌面拌菜
蒜蓉辣椒酱 / 剁椒 / 老干妈 万能救场
白胡椒 / 猪油 / 冷冻葱花 汤面提香三件套

六、一餐公式：照着做，不用想

  1. 麻辣一锅端（5 分钟）：水开 → 放一小块火锅底料 → 下丸子 + 冻豆腐 → 两分钟后下绿叶菜 + 挂面 → 关火打蛋花 + 香油。
  2. 饺子加蘸水（3 分钟）：速冻饺子水开下锅，浮起后再煮 3 分钟 → 蘸醋 + 生抽 + 辣椒油 + 蒜蓉。
  3. 清汤面（3 分钟）：挂面下锅 → 一块浓汤宝 → 两颗丸子 + 一把青菜 → 加个荷包蛋。
  4. 白灼菜配蛋（5 分钟）：鸡蛋煮 8 分钟 → 同一锅水焯生菜 20 秒 → 生抽 + 香油 + 蒜末。
  5. 螺蛳粉一锅出（12 分钟）：粉煮 8 分钟捞起 → 料包 + 酸笋 + 腐竹 + 花生 → 再加一把娃娃菜和丸子，管饱。
  6. 零卡充数（3 分钟）：魔芋丝 + 金针菇 + 豆芽 + 紫菜虾皮汤。饿了但不想长肉时用。

七、避坑

  • 四季豆 / 豆角 / 芸豆必须煮透 5 分钟以上，半生含皂苷，会吐。
  • 贝类要吐沙，开口即食，不开口的直接扔。
  • 速冻食品别反复解冻。买回来就按一顿的量分装保鲜袋，否则整袋坨成一团。
  • 内酯豆腐别久煮，会散；嫩豆腐用开水烫一下就够了。
  • 丸子 + 火腿肠钠含量极高，一天一顿封顶。
  • 挂面 / 粉丝水要多、火要大，煮过头就糊成一锅浆。
  • 腐竹、木耳、干香菇是这份清单里唯一需要提前泡的。想吃的话，出门上班前泡上。

八、采购节奏

  • 绿叶菜别囤，三天买一次。
  • 挂面、粉丝、干米粉、火锅底料、螺蛳粉占地小、保质期长，一次囤足。
  • 速冻类买回来先分装再冷冻，比什么都重要。

第一批（一人吃两周，约 350–450 元）

速冻水饺 1kg、速冻馄饨 500g×2、挂面 1kg、龙口粉丝 300g、意面 500g、螺蛳粉 5 袋装、火锅底料小块装、浓汤宝、潮汕牛肉丸 500g、鱼豆腐与蟹柳各 500g、冻豆腐与油豆腐、鸡蛋 30 枚、紫菜 + 虾皮 + 裙带菜、生抽 + 香油 + 蒜蓉辣酱、魔芋丝 3 包。

第二批（补口感）

玉米、红薯、午餐肉罐头、即食鸡胸肉、虾仁、冻蔬菜粒、芝麻酱。

在哪买

  • 叮咚买菜 / 美团买菜 / 盒马：绿叶菜、豆腐、虾仁、丸子，三十分钟送到，适合不做饭的人。
  • 大润发 / 永辉 / 山姆：速冻饺子、丸子、螺蛳粉整箱、火锅底料，单价最低。
  • 山姆 / 麦德龙：潮汕牛肉丸、虾滑、冷冻海鲜，大包装最划算。
  • 拼多多 / 淘宝：火锅底料小块装、粉丝、挂面、螺蛳粉整箱，囤货最便宜。

清单本身没什么技术含量，唯一的心得是：一个人住做饭最大的成本不是厨艺，是洗碗。所以能一锅出的，就别分两口锅。
